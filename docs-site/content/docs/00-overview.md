# 概览

MetaFusion 是**元数据开放、媒体受控**的高质量多媒介典藏与流媒体平台。定位不是封闭私库，而是可被搜索引擎收录、可被应用与 Agent 复用的开放百科 + 受控媒体仓库的结合体。

## 一句话定位

> **开放的目录，受控的媒体。** 任何人可浏览与检索全部编目元数据；只有登录用户可播放、预览与下载实际媒体二进制。

## 适合谁

- **听众/观众/读者**：在探索页按媒介、分类、标签、创作者图谱发现作品。
- **编辑/考据者**：按 FRBR 五级模型进行严谨编目，提供来源与修订历史。
- **开发者/Agent**：通过 MusicBrainz WS/2 风格的 Lookup / Browse / Search + PAT 令牌复用全部网页能力。
- **站务**：通过后台审核、封禁、审计与系统开关保障合规与风控。

## 访问模型（先记住这张表）

| 可见性 | 是否需登录 | 内容 |
|---|---|---|
| L0 开放 | 否 | Work/Release/Medium/Track/Artist 元数据、搜索、社区帖子文字、首页/探索/榜单、缩略图 |
| L1 受控 | 是 | 原档下载、HLS/音频/图像预览流、上传、发帖/回帖、私信、邀请信息 |

> Nginx 对 `/storage/preview/*` 与预签名直链的透传必须校验 JWT，直链外泄不得绕过鉴权。`metafusion-preview` 桶不得设为 public。

## 技术栈一瞥

```
[ Next.js 15 前端 + /admin ] ──> [ Nginx :80 ] ──> [ Go API :8080 ] ──> [ Postgres / Redis / ES / MinIO ]
                                        └─> [ docs-site :3001 ]  ← 你正在阅读的独立文档站
```

本文档站独立于主站与管理后台部署，内容由 `docs-site/content/docs/` 的 Markdown 驱动，构建为静态页面，随主栈一键 `docker compose up` 拉起。
