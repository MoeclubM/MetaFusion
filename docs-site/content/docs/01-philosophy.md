# 理念与价值观

## 为什么是开放目录

封闭私库解决了短期私密性，却制造了长期孤岛：元数据无法被索引、无法被引用、无法被再利用。MetaFusion 选择图书馆学的路径——**目录开放，载体受控**。

- **可发现性**：游客与搜索引擎可直接打开任意 Work/Release/Artist 详情与搜索结果。
- **可引用性**：每条实体有稳定 ID 与修订历史，适合论文、Wiki、Agent 的可靠引用。
- **可再利用**：开放 API 让个人应用、社区机器人、研究脚本无需逆向网页即可同步元数据。

## 邀请制的真实含义

邀请不是付费墙，也不是身份门槛，而是**风控与合规缓冲层**。

- 抑制批量注册、机器爬取媒体、女巫刷取与垃圾内容；
- 为媒体二次分发提供可追溯的邀请链（`users.invited_by`），便于审计与溯源；
- 由后台 `system_settings.registration_enabled` 与 `invite_required` 动态开关，无需改代码即可在活动期临时开放。

## 考据而非堆砌

每一次创建或编辑都要求 `edit_note` 与 `source_urls`。这不是形式主义：

- **可追溯**：谁在何时基于什么来源做了什么改动，写入 `entity_revisions`；
- **可合并**：重复实体通过 `POST /catalog/merge` 合并，历史得以保留而非丢失；
- **可信任**：来源越充分，审核越顺畅，社区越愿意复用你的数据。

## 长期保存

- **PB 级双轨存储**：原档进冷桶 `metafusion-master`，预览切片进热桶 `metafusion-preview`，控制面与数据面分离，直传绕过业务服务。
- **全文件 SHA-256 秒传去重**：同一文件不重复落盘，但不复用他人鉴权。
- **多媒介转码**：影视 HLS + 雪碧图、音频 320k 预览 + 波形、图书 EPUB 流式 + 图像 WebP 双页。

## 非目标

- 不做 Karma/积分体系（若未来引入另行 PRD）；
- 不将邀请与内容分级挂钩；
- 不为媒体 URL 提供无鉴权直链（`robots.txt` 禁止索引二进制）。
