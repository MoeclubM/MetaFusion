# 平台概览

MetaFusion 是一个**开放媒体资源站与元数据共建平台**，专注于 ACG、音乐、影视、文学等多元媒体资源的收录与结构化整理。

## 核心定位

> **公开元数据，受控媒体资源。** 平台提供全量公开的元数据索引、结构化分类检索、自由词条编辑与社区贡献能力，并支持完整的开放 API 与 Agent 程序化调用。

## 目标群体

- **普通用户**：在探索页按媒介类型、分类、标签规则、创作者图谱发现优质作品与资源。
- **编辑与共建者**：基于 FRBR 四层规范进行结构化编目，补充作品背景、外部权威链接与修订说明。
- **开发者与 Agent**：通过 MusicBrainz WS/2 风格的 Lookup / Browse / Search API 与 PAT 访问令牌，程序化调用全站能力。
- **管理团队**：通过后台审核、审计日志与系统开关维护社区秩序与合规运营。

## 文档导航

- **核心理念**：开放元数据目录的建设原则与邀请机制
- **快速上手**：5 分钟完成注册、探索资源与创建第一条元数据
- **资源体系**：FRBR 四层实体分层、分类规则与动态标签系统
- **编辑与投稿**：词条创建、实体合并、分片上传与音频流媒体转码
- **开放 API**：PAT 认证、实体查询、全文检索与 Agent 自动化接入
- **服务与合规**：服务条款、隐私政策、版权与 DMCA 处理机制

## 访问与权限模型

| 模块 | 权限要求 | 内容与能力 |
|---|---|---|
| 基础元数据 | 需登录/鉴权 Token | Work / Release / Medium / Track / Artist 详情、分类标签图谱、全文搜索、社区讨论 |
| 资源操作 | 需登录用户 | 原档下载、音视频预览流播放、资源分片上传、发帖/回帖、私信交流、PAT 令牌管理 |
| 词条维护 | 需登录用户 | 新建作品/发行版/创作者、修改元数据、提交合并申请、查看修订历史 |
| 系统管理 | 管理员/考据员 | 站点配置、审核流转队列、板块管理、审计日志与数据统计 |
