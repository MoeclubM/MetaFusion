# 词条编辑与合并规范

MetaFusion 是一个由社区共同维护的开放元数据资源平台。所有注册用户均可参与词条创建、元数据修正与实体合并。为了保障全站元数据的准确性、一致性与可检索性，请在编辑时遵循以下规范。

---

## 1. 基本编辑原则

- **客观考据**：词条信息应基于官方网站、发行物包装、权威数据库（如 MusicBrainz、VGMdb、Bangumi、IMDb 等）客观录入，避免主观评测或个人感想。
- **信息完整**：在创建或编辑作品时，尽量完善原名、外文名、发行日期、分类标签、制作团队及封面图片。
- **改动说明（Edit Note）**：每次提交修改时，请简要说明修改原因或信息来源，便于社区审核与历史追溯。
- **来源引用（Source URLs）**：附带可验证的参考链接（如官网介绍页、权威条目页），有助于提升词条可信度。

---

## 2. 词条命名与多语言规范

### 作品与发行版命名
- **首选原名**：优先使用作品官方原始发行语言的名称（如日文原名、英文原名）。
- **多语言别名**：在“多语言翻译/别名”中补充中文译名、英文译名及拼音/罗马字，以便全球用户和不同输入习惯的读者检索。
- **标点符号**：使用半角或全角标点应与官方原始排版保持一致；副标题推荐使用空格或冒号分隔。

### 创作者命名
- **个人与团体**：优先使用创作者最广为人知的官方艺名/常用名；对于一人多艺名的情况，建议建立主实体并在别名中补充其他艺名。
- **多重身份**：创作者实体独立于具体作品，通过作品中的“身份角色”（如监督、声优、作词、作曲）建立关联，切勿按作品重复创建同一人物。

---

## 3. FRBR 实体层级拆分准则

录入多媒体资源时，请按照平台的四层架构清晰拆分：

| 实体层级 | 对应内容 | 举例 |
|---|---|---|
| **作品 (Work)** | 抽象创作概念与核心母题 | 《攻壳机动队》剧场版、《残酷天使的行动纲领》 |
| **表现 (Expression / CanonicalEntry)** | 具体的创作表达、篇章正文、录音母带或成片剪辑 | 原版立体声母带、导演剪辑版正片、正文典范章节、2020 重制版 |
| **发行 (Release)** | 商业发售或发布的具体出版包 | 2003 发行的初回限定版 CD (Catalog No: KICA-1234) |
| **载体与曲目 (Medium & Track)** | 物理/数字介质与曲目编号 | Disc 1 (CD) 中的 Track 01、单行本第 1 卷 |

---

## 4. 外部权威标识关联

为打破数据孤岛并支持自动化识别，平台支持为实体关联外部权威 ID。建议录入时补充以下标识：
- **音乐类**：MusicBrainz ID, VGMdb ID, ISRC
- **动画/影视类**：Bangumi ID, AniList ID, IMDb ID, TMDb ID
- **文学/出版物**：ISBN, VNDB ID (视觉小说), 豆瓣读书 ID

---

## 5. 实体消歧与重复合并准则

### 何时需要合并
当发现平台中存在同一实体被重复创建时（例如因译名不同创建了两个《EVA》条目）：
1. **确认同一性**：比对官方编号、创作者与发行日期，确认确实指向同一个物理或数字作品。
2. **选择保留主体**：选择创建时间较早、元数据较完善或关联资源较多的实体作为目标实体（Target）。
3. **发起合并**：在实体管理工具中提交合并申请，填写合并理由（如“与官方条目重复，合并至早期完整条目”）。

### 合并后的数据处理
- 系统会自动将原实体的关联关系、曲目、修订历史迁移至目标实体。
- 原实体将标记为“已合并”状态，并自动重定向至目标实体，确保旧链接不失效。

---

## 6. 违规与争议处理

- **恶意破坏与灌水**：严禁提交虚假信息、恶意清空元数据或批量灌水垃圾内容。违规账号将被限制编辑权限。
- **观点与分类争议**：对于作品题材、分类或标签存在争议的情况，可在社区“文献与考据讨论”板块发帖交流，由社区共同讨论或站务协助判定。
- **历史回退**：如遇误操作，可通过实体详情的“修订历史 (Revision History)”查看历史差异并申请恢复至指定版本。
