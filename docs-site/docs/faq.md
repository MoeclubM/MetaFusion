# 常见问题（FAQ）

## 邀请与注册

**Q：现在注册需要邀请码吗？**  
A：取决于当前站点的运行配置。打开登录注册页面时，表单会动态提示是否需要填写邀请码。活动期间平台可能会临时开放免邀请公开注册。

**Q：在哪里获取我的邀请码？**  
A：已注册用户可在个人中心「邀请管理」页面（`/invites`）查看自己的专属 `MF-` 永久邀请码与剩余生成配额。

## 浏览与媒体

**Q：游客能浏览哪些内容？**  
A：全量基础元数据（作品、发行版、创作者、分类标签、实体图谱、全文搜索及社区公开讨论）。点击播放音视频、下载原档、上传资源或在社区发帖时，系统会引导登录。

**Q：为什么媒体资源提示无法播放或无权限？**  
A：媒体资源（原档与预览切片）受到访问控制保护，仅对已登录用户开放。请确认当前处于登录状态；若在外部脚本或第三方客户端中访问，请确保已配置有效的个人访问令牌（PAT）。

**Q：封面为什么无法正常显示？**  
A：平台对封面链接有安全性校验机制。建议使用系统内置的本地文件上传，或填写可信图床的直接图片链接。

## 编辑与审核

**Q：为什么提交的词条或修改被退回？**  
A：常见原因包括：缺少修改说明（Edit Note）、缺少参考来源链接（Source URLs）、标题命名或图谱关联有误、或者属于重复创建。根据考据员在审核意见中给出的提示修正后重新提交即可。

**Q：如何避免创建重复的词条？**  
A：在新建词条前，请先在顶部搜索栏输入作品原名、罗马音、常见译名或唱片编号进行充分检索，优先完善与复用已有条目。

## 开发者与 API

**Q：未登录（匿名访问）支持通过程序调用哪些数据？**  
A：平台所有公开元数据（作品目录、实体详情、检索服务、分类标签、图谱关系及社区讨论等）均支持公开只读调用；涉及内容写入、媒体上传、原档下载等敏感操作则必须携带有效的个人访问令牌（PAT）。

**Q：为什么通过 API 写入数据时提示错误？**  
A：请确认客户端请求头中已包含规范的 `User-Agent`（如 `MyApp/1.0 (you@example.com)`），并在请求体中附带了 `edit_note`（修改说明）或 `source_urls`（参考来源）。详情请查阅 [开发者 API 概览](/api-overview)。

**Q：平台接口调用频率限制是多少？**  
A：匿名未登录请求上限为 60 次/分钟，登录及 PAT 认证请求上限为 600 次/分钟。响应头包含限流状态信息，触发限流时请适当退避重试。

## 部署与运维

**Q：部署时 OpenSearch 未启动会影响正常使用吗？**  
A：系统具备自动降级机制，搜索功能会自动降级为数据库检索，不影响全站的基础浏览与编目。公网部署时建议将 OpenSearch 置于内网环境或开启安全认证。

**Q：文档站如何访问与本地预览？**  
A：线上环境可通过 `/docs/` 直接访问（由网关自动代理）；本地独立开发可在 `docs-site` 目录下运行 `npm run dev` 进行预览。
