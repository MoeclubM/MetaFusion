# 版权与 DMCA

## 1. 基本原则

- MetaFusion 是资源收录与编目平台，**不鼓励亦不支持侵权分发**。
- 媒体预览与下载页需展示版权与合规提示，下载行为需二次确认。
- 元数据（事实性信息、结构化描述）与媒体二进制（受版权保护的文件）适用不同规则：前者开放，后者受控且需合规使用。

## 2. 提交保证

- 你保证拥有提交内容的必要权利，或属于合理使用、公共领域、已获授权。
- 鼓励提供 `source_urls` 与 `edit_note` 以证明来源与考据过程。

## 3. 侵权投诉（DMCA 风格）

若你认为站内内容侵犯你的版权，请通过[联系方式](/contact)提交：

- 权利人身份与联系方式
- 被侵权作品的描述与权属证明
- 侵权内容在站内的具体 URL（Work/Release/Asset ID 与链接）
- 声明“善意相信该使用未经授权”与“信息准确、愿承担伪证责任”

站务将在核实后下架或限制访问，并通知上传者。

## 4. 反通知

上传者若认为下架有误，可提交反通知，说明权属或合理使用依据，站务复核后决定是否恢复。

## 5. 重复侵权

重复侵权或恶意投诉的账号将被限流或封禁，邀请链将作为溯源依据之一。

## 6. 技术措施

- 媒体 URL 需鉴权，`robots.txt` 禁止直链索引
- 速率限制与审计日志用于防止批量外泄
