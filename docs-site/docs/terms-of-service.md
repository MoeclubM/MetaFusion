- 站务可基于 `system_settings` 动态开关注册与邀请要求。

- 禁止：侵权内容、未授权的大规模抓取、垃圾信息、恶意脚本、规避鉴权与限流。

## 4. 元数据开放与媒体受控

- 元数据（Work/Release/Artist 等）默认开放可被索引与通过 API 复用，遵循本条款与站内署名要求。
