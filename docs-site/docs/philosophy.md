# 核心理念与定位

## 开放元数据

MetaFusion 致力于构建开放、规范的多媒体资源与元数据共建库：

- **高度结构化**：遵循 FRBR 规范，区分作品理念、具体表现、发行实体与存储载体。
- **稳定可引用**：每条实体具备固定 UUID 与版本修订历史，便于跨平台引用与元数据集成。
- **开放互联**：提供标准 REST API，支持个人应用、社区工具与 AI Agent 无缝调用。

## 社区共建与考据精神

词条创建与编辑遵循可追溯与可考据原则：

- **版本追溯**：实体修改记录于 `entity_revisions`，支持对比历史差异与撤销变动。
- **实体合并**：针对重复收录的词条，支持通过合并流程保留关联关系与贡献历史。
- **来源可信**：鼓励在编辑时补充 `edit_note` 与参考来源 `source_urls`，提升数据准确性。

## 分层存储与流媒体优化

- **冷热分离存储**：母盘原档存储于冷存储桶，预览切片与低码率流存储于热存储桶，保障传输性能。
- **秒传去重**：基于文件 SHA-256 哈希实现存储去重。
- **多媒体处理**：音视频转码生成 HLS 流、波形图及 WebP 预览，保障多终端流畅访问。

## 邀请机制

邀请机制用于保障社区建设质量与合规运营：

- 维护健康的社区交流环境与高质量的元数据维护梯队；
- 提供清晰的邀请追溯链，保障资源贡献的可信度；
- 后台可动态开启或关闭公开注册与邀请码要求。
