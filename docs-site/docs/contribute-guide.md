# 资源收录与投稿标准

为了保障全站资源的长期可用性与播放体验，MetaFusion 对投稿收录的媒体资源与元数据制定了以下标准。

---

## 1. 投稿流程

1. **查重确认**：在提交前，请先在搜索栏进行检索，确认平台尚未收录该发行版本，避免重复录入。
2. **填写元数据**：在 [投稿中心](/contribute) 填写作品标题、发行日期、分类标签及参考来源。
3. **上传物理资源**：选择本地文件分片直传至对象存储，支持断点续传。
4. **提交审核**：提交后条目进入审核队列，由考据员审核通过后全站呈现。

---

## 2. 媒体格式建议

| 媒介类型 | 推荐格式 | 说明 |
|---|---|---|
| **无损音频** | FLAC, ALAC, WAV (16/24-bit) | 平台会自动转码生成 320kbps 预览流与波形图，原档完好保留 |
| **有损音频** | MP3 (320kbps), AAC (256kbps+) | 适合体积极致轻量化的原声或广播剧 |
| **视频影像** | MP4 (H.264/HEVC), MKV | 平台会自动切片生成多码率 HLS 流与雪碧图预览 |
| **电子书刊** | EPUB, PDF, CBZ/CBR | 适合漫画画集与小说文献 |
| **封面图片** | JPG, PNG, WebP (建议分辨率 ≥ 1000x1000) | 保持高清方图，无多余水印 |

---

## 3. 审核状态说明

- **待审核 (Pending)**：新提交的资源已入库，等待考据员核验元数据与文件完整性。
- **已通过 (Approved)**：核验通过，条目对全站用户公开，出现在搜索与推荐列表。
- **需修正 (Needs Revision)**：考据员在审核意见中指出缺失信息（如缺少来源、曲目顺序颠倒等），贡献者可在编辑后重新提交。

---

## 4. 贡献者荣誉与历史

- 用户的每一次有效贡献都会记录在个人主页的 **“贡献历史”** 中。
- 高质量的持续贡献者可申请成为社区 **考据员 (Archivist)**，获得直接审核与词条锁定的权限。
