# 媒体上传与转码流

MetaFusion 采用现代化的对象存储与分布式转码架构，确保大文件上传稳定可靠，并在各种设备上都能获得即时流畅的播放体验。

---

## 1. 分片断点直传

- **直接上传至存储桶**：客户端直连分布式对象存储集群，不占用主 API 服务器带宽，上传速度不受网关性能瓶颈限制。
- **分片与断点续传**：大文件被智能拆分为多个分片并行上传。若遇网络抖动中断，重新选择同一文件即可自动从断点继续传输，无需从头重传。
- **SHA-256 秒传去重**：上传前在本地计算文件特征哈希。若平台存储中已存在相同二进制文件，系统将直接完成秒传复用，节省带宽与存储空间。

---

## 2. 异步转码与多码率分发

文件上传成功后，系统工作节点会自动启动后台异步转码任务：

- **音频处理**：
  - 母盘原档安全归档；
  - 自动抽取元数据标签（ID3 / Vorbis Comments / 嵌入封面）；
  - 自动生成 320kbps AAC/MP3 预览音频流与 100 点音频波形数据，供底栏播放器实时渲染。
- **视频处理**：
  - 生成多码率自适应 HLS 流（.m3u8 切片），根据用户当前网络带宽自动平滑切换画质；
  - 生成时间轴视频缩略图（雪碧图），支持播放进度条悬停快速预览。
- **图像与文档**：
  - 自动压缩生成 WebP 高清缩略图与移动端自适应小图。

---

## 3. 安全与访问控制

- **原档下载受控**：只有登录认证用户可获取具备有效时限的临时下载签名 URL，防止未授权盗链与自动化滥用。
- **预览流鉴权保护**：所有流媒体切片均受到访问控制保护，确保平台资源安全可控。
