# MetaFusion 项目开发技能

本技能是 `AGENTS.md` 的简短入口，不重复维护项目规则。

## 执行提示

- 涉及部署、本机路径或已知环境时，按需读取 `docs-local/`；只在产生可复用的新事实、决定或已知坑时更新，不写操作流水。
- 优先做最小必要修改，保留已有改动；接口、行为或部署方式变化时，只同步直接受影响的文档与契约。
- 注释说明原因和约束，不复述代码；不设置机械的文件长度阈值。
- 以实际处理器、已执行迁移、definitions 和 taxonomy 为事实来源，不用文档旧描述绕开运行时行为。
- 按改动范围和风险验证，报告证据、限制和未完成项。

真实凭据不得进入版本库、日志、报告或对话；本机使用的凭据文件必须保持被忽略。
